# Генератор паролей

Групповой учебный проект на Python: настольное приложение для генерации паролей с графическим интерфейсом на Tkinter.
Сделан в рамках ознакомительной практики в июне 2025 года. Работали через ветки и pull request'ы, правила совместной работы описаны в [CONTRIBUTING.md](CONTRIBUTING.md).

**Команда:** Рафаэль Миниханов (владелец репозитория), Игорь Жаховский, Кирилл Гаврилов, Алиса Клюева.

## Возможности

- длина пароля и наборы символов: буквы, цифры, спецсимволы;
- два алгоритма:
  - `default` — случайные символы из выбранных наборов;
  - `strict` — гарантирует хотя бы один символ из каждого выбранного набора;
- копирование пароля в буфер обмена;
- сохранение, загрузка и сброс настроек (JSON).

## Структура

| Файл | Назначение |
|---|---|
| `main.py` | окно приложения и меню (Tkinter) |
| `password_generator.py` | логика генерации паролей |
| `settings.py` | настройки, их сохранение и загрузка |
| `test.py` | модульные тесты (unittest) |

## Запуск

Нужен Python 3 с Tkinter.

```bash
pip install pyperclip
python3 main.py
```

Тесты:

```bash
python3 test.py
```
